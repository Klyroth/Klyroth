## 🎮 My Games

### [The real SK](https://github.com/Klyroth/the-real-sk)
FPS zombie survival game in Unity (URP). Waves of zombies, 4 rifles, 2 city maps, menus, settings and save system. Android APK built with Unity Build Automation.

### [Horror Night](https://github.com/Klyroth/horror-night)
FPS horror survival game set in a dark foggy city. Flashlight, sniper rifle, endless zombie waves, touch controls for Android. Android APK built with Unity Build Automation.

### [SK First Game](https://github.com/Klyroth/sk-first-game)
My first 3D adventure game built with Unity (URP) — terrain, player character and a playable world. Android APK built with Unity Build Automation.
